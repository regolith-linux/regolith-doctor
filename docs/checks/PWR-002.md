# PWR-002: Idle, blank and suspend configured in a way that is ignored or doubled

| | |
|---|---|
| Area | PWR |
| Sessions | i3 (X11) and sway (Wayland) |
| Releases | Regolith 3.4, 3.5 |
| Needs | files only |
| Fix class | report-only |
| Status | planned |

## What it detects

A user swayidle runs next to the one from regolith-powerd, GNOME power settings are expected to apply on sway, the screen blank is set to 'never' while locking is on, or an older powerd treats an unknown power source as a battery.

## How it is detected

The doctor reads `exec` lines, the GSettings keys of `org.gnome.settings-daemon.plugins.power` and `idle-delay` of `org.gnome.desktop.session`, and the installed powerd version (see PKG-008).

## Fix

The doctor explains which setting wins and which one is ignored. Report-only: nothing is changed.
