# CFG-008: A binding or autostart runs a program that is not there

| | |
|---|---|
| Area | CFG |
| Sessions | i3 (X11) and sway (Wayland) |
| Releases | Regolith 3.4, 3.5 |
| Needs | files only |
| Fix class | report-only |
| Status | planned |

## What it detects

An `exec`, `bindsym ... exec`, `status_command` or `wm.program.*` value whose program does not exist: an absolute path into a source build, a `/snap/bin` path, a script an update removed, or a helper whose package is missing. The key or autostart silently does nothing.

## How it is detected

Takes the first real word of the command (after `--no-startup-id`, `systemd-run --user --scope`, `env VAR=...` and `sh -c`) and resolves it against the PATH directories under the root and the user's session PATH (see LNCH-001), then checks that it is executable.

## Fix

Reports the missing program and suggests the Regolith default where one exists. Report-only: the doctor changes nothing.
