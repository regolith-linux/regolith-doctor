# PKG-006: Removed but not purged Regolith packages leave active config

| | |
|---|---|
| Area | PKG |
| Sessions | i3 (X11) and sway (Wayland) |
| Releases | Regolith 3.4, 3.5 |
| Needs | files only |
| Fix class | guided |
| Status | planned |

## What it detects

A package was removed but not purged, and its conffiles (blocklet configs, partials under `/etc`) still call scripts that are gone. Symptoms are a flooded journal or a loop using a full CPU core (`next-workspace-widget: not found`).

## How it is detected

The doctor finds packages with `Status: deinstall ok config-files` in `/var/lib/dpkg/status`, lists their `Conffiles:` that still exist, and checks whether the commands those files reference still exist.

## Fix

The doctor suggests `apt purge <pkg>` or moving the stale conffile aside. Guided: applied after you confirm.
