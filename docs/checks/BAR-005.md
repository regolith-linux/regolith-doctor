# BAR-005: Bar settings changed by copying the bar partial instead of using resources

| | |
|---|---|
| Area | BAR |
| Sessions | i3 (X11) and sway (Wayland) |
| Releases | Regolith 3.4, 3.5 |
| Needs | files only |
| Fix class | guided |
| Status | planned |

## What it detects

The user changed the bar font, position or status command by copying the bar partial (or the i3status-rust config) instead of setting `wm.bar.*` resources. The copy misses later fixes, and a user i3status-rust config that fails to parse leaves the bar empty.

## How it is detected

The doctor compares user `bar {}` blocks with the `wm.bar.*` keys that would do the same, and parses any user i3status-rust TOML config.

## Fix

The doctor offers the resource lines that replace the copied settings. Guided: the change is shown and applied only after you confirm.
