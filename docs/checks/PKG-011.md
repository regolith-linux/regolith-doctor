# PKG-011: Default terminal or browser alternative points somewhere unexpected

| | |
|---|---|
| Area | PKG |
| Sessions | i3 (X11) and sway (Wayland) |
| Releases | Regolith 3.4, 3.5 |
| Needs | files only |
| Fix class | guided |
| Status | planned |

## What it detects

The `x-terminal-emulator` alternative still points at a removed terminal (or at `regolith-st`), so Super+Enter does nothing, or an uninstall left the alternative changed.

## How it is detected

The doctor reads `/var/lib/dpkg/alternatives/x-terminal-emulator` and `x-www-browser` (current link and priorities) and resolves the `/etc/alternatives/*` symlink inside the root to check that the target exists. If `wm.program.terminal` is set in the resources it is checked too.

## Fix

The doctor shows `update-alternatives --config x-terminal-emulator` or suggests setting `wm.program.terminal`. Guided: you confirm before anything changes.
