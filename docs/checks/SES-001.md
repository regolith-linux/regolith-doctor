# SES-001: Session cannot start: missing session files or programs

| | |
|---|---|
| Area | SES |
| Sessions | i3 (X11) and sway (Wayland) |
| Releases | Regolith 3.4, 3.5 |
| Needs | files only |
| Fix class | guided |
| Status | planned |

## What it detects

Logging in loops back to the greeter or shows a black screen, or the Sway session is missing from GDM. Causes: `regolith-x11.desktop` or `regolith-wayland.desktop` is missing, its `Exec` target is gone, `i3-wm` or `sway-regolith` is not installed, or files under `/etc/regolith` were deleted.

## How it is detected

The doctor reads `/usr/share/xsessions/regolith*.desktop` and `/usr/share/wayland-sessions/regolith*.desktop`, checks their `Exec` and `TryExec` targets under the root, and checks the programs the session scripts need. Deleted conffiles are covered by PKG-007.

## Fix

The doctor names the package to install or reinstall. Guided: applied after you confirm.
