# PWR-003: Lock and brightness safety

| | |
|---|---|
| Area | PWR |
| Sessions | i3 (X11) and sway (Wayland) |
| Releases | Regolith 3.4, 3.5 |
| Needs | files only |
| Fix class | report-only |
| Status | planned |

## What it detects

Brightness keys are not bound with `--locked`, so turning brightness down to zero can lock you out of a locked screen; or the lock program resource is unset or points at a locker that is not installed.

## How it is detected

The doctor checks the flags of the effective brightness bindings, reads the lock resources and resolves the lock program.

## Fix

The doctor reports the problem and, when an upgrade contains the fix, says so. Report-only: nothing is changed.
