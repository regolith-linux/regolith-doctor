# APT-002: Regolith source points at a retired host or the old Launchpad PPA

| | |
|---|---|
| Area | APT |
| Sessions | i3 (X11) and sway (Wayland) |
| Releases | Regolith 3.4, 3.5 |
| Needs | files only |
| Fix class | guided |
| Status | planned |

## What it detects

An apt entry still uses an address Regolith no longer serves: `regolith-desktop.io`, `regolith-desktop.org`, the Debian host retired in March 2026, an S3 bucket URL, or `ppa.launchpad.net/regolith-linux`. apt shows certificate errors, 403 or 404 replies, `NO_PUBKEY`, or packages that are not installable. Systems installed long ago often still carry these.

## How it is detected

The same source parser as APT-001 reads every entry. Hosts and paths are matched against a table shipped with the doctor that lists each retired endpoint, when it was retired and what replaced it (`https://archive.regolith-desktop.com/{ubuntu,debian}/<channel> <codename> v<series>`).

## Fix

The doctor replaces the entry with the current address for this system, keeping channel and series, and backs up the old file. For a PPA entry it also removes the PPA's own list file. Guided: nothing changes until you confirm.
