# APT-009: Regolith packages installed but no Regolith source configured

| | |
|---|---|
| Area | APT |
| Sessions | i3 (X11) and sway (Wayland) |
| Releases | Regolith 3.4, 3.5 |
| Needs | files only |
| Fix class | guided |
| Status | planned |

## What it detects

Regolith packages are installed, for example from an ISO or after a cleanup of the source files, but no enabled apt entry provides them, so they never receive updates.

## How it is detected

The doctor finds no enabled Regolith entry in the parsed sources while `/var/lib/dpkg/status` lists installed `regolith-*` packages. The codename and series in the installed versions tell which source to suggest.

## Fix

The doctor offers the matching source line and, if needed, the keyring (see APT-003). Guided: added only after you confirm.
