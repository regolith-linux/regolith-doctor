# PKG-010: Obsolete packages from Regolith 1.x/2.x still installed

| | |
|---|---|
| Area | PKG |
| Sessions | i3 (X11) and sway (Wayland) |
| Releases | Regolith 3.4, 3.5 (old installs upgraded in place) |
| Needs | files only |
| Fix class | guided |
| Status | planned |

## What it detects

Packages from old Regolith releases survived upgrades: `i3-gaps-wm` shadowing Regolith's `i3-wm`, `regolith-i3-gaps-config`, the 1.x `remontoire`, `regolith-styles`, or compton packages.

## How it is detected

The doctor checks `/var/lib/dpkg/status` against a list of obsolete package names and their replacements shipped with the doctor.

## Fix

The doctor shows the remove and install pair. Guided: run only after you confirm.
