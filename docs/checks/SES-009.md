# SES-009: Regolith components crashed recently

| | |
|---|---|
| Area | SES |
| Sessions | i3 (X11) and sway (Wayland) |
| Releases | Regolith 3.4, 3.5 |
| Needs | files only |
| Fix class | report-only |
| Status | planned |

## What it detects

i3, sway, i3xrocks, ilia, picom, rofication, regolith-displayd, -inputd, -powerd or the control center crashed, or user units failed at login.

## How it is detected

The doctor reads apport reports in `/var/crash/*.crash` (`ExecutablePath`, `Package`, date). In a running session it also reads `coredumpctl --json`, `systemctl --user --failed` and `journalctl --user -b`.

## Fix

The doctor reports the crash with the package version and any known-bug match from PKG-008. Report-only.
