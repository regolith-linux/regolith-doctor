# PKG-001: Regolith packages from more than one release (mixed versions)

| | |
|---|---|
| Area | PKG |
| Sessions | i3 (X11) and sway (Wayland) |
| Releases | Regolith 3.4, 3.5 |
| Needs | files only |
| Fix class | guided |
| Status | planned |

## What it detects

Some installed Regolith packages (`regolith-*`, `i3-wm`, `sway-regolith`, `ilia` and the like) were built for another codename or an older series, for example `-1regolith-lunar` on jammy. Symptoms include raw markup in the bar, dependencies that cannot be satisfied, and `--builtin` passed to gnome-session 46 or later.

## How it is detected

The doctor reads installed packages from `/var/lib/dpkg/status`, extracts the `regolith-<codename>` suffix (and older `ppa` or `focal1` style suffixes) from each version, and compares it with the system codename and with what most packages carry. Outliers are grouped together.

## Fix

The doctor lists the outliers and the `apt install <pkg>=<version>` or full upgrade that aligns them, using versions from `/var/lib/apt/lists/*_Packages` when present. Guided: commands are shown and run only after you confirm.
