# SES-005: Login scripts that abort the session

| | |
|---|---|
| Area | SES |
| Sessions | i3 (X11) and sway (Wayland) |
| Releases | Regolith 3.4, 3.5 |
| Needs | programs installed on the system, no running session |
| Fix class | report-only |
| Status | planned |

## What it detects

An error or an `exit` in `~/.profile`, `~/.xprofile` or `~/.xsessionrc` ends the login before the desktop appears.

## How it is detected

The doctor runs `sh -n` on each file for syntax errors and looks for a top-level `exit` or `exec`, and for `set -e` followed by commands that can fail.

## Fix

The doctor reports the offending line. Report-only: the file is not changed.
