# PKG-005: Two packages installed that should not be installed together

| | |
|---|---|
| Area | PKG |
| Sessions | i3 (X11) and sway (Wayland) |
| Releases | Regolith 3.4, 3.5 |
| Needs | files only |
| Fix class | guided |
| Status | planned |

## What it detects

Pairs that conflict are both installed: both control-center variants, `regolith-wm-ilia` with `regolith-i3-ilia`, the distribution's `sway` next to `sway-regolith`, or `regolith-styles` with `regolith-session-common` (both ship `/usr/bin/regolith-look`). The result is the wrong binary or config winning.

## How it is detected

The doctor checks `/var/lib/dpkg/status` against a table of conflicting pairs per series shipped with the doctor, and scans `/var/lib/dpkg/info/*.list` for a path owned by two packages.

## Fix

The doctor shows which package to remove and what depends on it. Guided: removal happens only after you confirm.
