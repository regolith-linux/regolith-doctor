# PKG-003: Regolith upgrades kept back or held

| | |
|---|---|
| Area | PKG |
| Sessions | i3 (X11) and sway (Wayland) |
| Releases | Regolith 3.4, 3.5 |
| Needs | files only |
| Fix class | guided |
| Status | planned |

## What it detects

A plain `apt upgrade` keeps Regolith packages back after a release that adds or drops dependencies, or a hold set with `apt-mark hold` or `dpkg --set-selections` is still on Regolith packages. The desktop stays partly on the old release.

## How it is detected

Holds show up as `Status: hold ...` in `/var/lib/dpkg/status`. For kept-back packages the doctor compares installed versions with candidates in the Regolith `*_Packages` files under `/var/lib/apt/lists/`, using Debian version comparison, and flags candidates whose `Depends` need new packages.

## Fix

The doctor recommends `apt full-upgrade` and offers to release the hold. Guided: nothing runs until you confirm.
