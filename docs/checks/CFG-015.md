# CFG-015: Running WM config is older than the files

| | |
|---|---|
| Area | CFG |
| Sessions | i3 (X11) and sway (Wayland) |
| Releases | Regolith 3.4, 3.5 |
| Needs | a running session (recorded output can be replayed) |
| Fix class | auto (a reload in the running session) |
| Status | planned |

## What it detects

The user edited partials or Xresources, but the running i3 or sway still uses the old config, because the config is only read at login or on reload.

## How it is detected

Compares the config the window manager reports (`i3-msg -t get_config` or `swaymsg -t get_config`, including the included files and their contents) with the files on disk, and the loaded resources with the files (see XRES-009).

## Fix

Offers `regolith-look refresh` and a window manager reload. Auto: the doctor may do this itself because a reload is harmless.
