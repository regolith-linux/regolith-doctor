# SES-003: Proprietary NVIDIA driver with the sway session

| | |
|---|---|
| Area | SES |
| Sessions | sway (Wayland) |
| Releases | Regolith 3.4, 3.5 |
| Needs | files only |
| Fix class | guided |
| Status | planned |

## What it detects

With the proprietary NVIDIA driver loaded, the Wayland session drops back to the login screen unless sway is started with `--unsupported-gpu`.

## How it is detected

The doctor checks `/proc/modules` or `/sys/module/nvidia` for the driver and reads the resource `regolith.sway.unsupported_gpu`.

## Fix

The doctor explains the situation and offers the resource line that enables the flag. Guided: added after you confirm.
