# CFG-009: Workspace assignment rules that cannot work

| | |
|---|---|
| Area | CFG |
| Sessions | i3 (X11) and sway (Wayland) |
| Releases | Regolith 3.4, 3.5 |
| Needs | files only |
| Fix class | report-only |
| Status | planned |

## What it detects

`assign` or `for_window ... move to workspace` rules that target a workspace number while workspaces have names such as `1: Term`, which creates a second workspace with the same number; `workspace N output X` for outputs that do not exist; workspace names without the `N:` prefix.

## How it is detected

Parses `assign`, `for_window ... move to workspace` and `workspace ... output` lines in the effective include list together with the `wm.workspace.NN.name` resources, and compares each target with the effective workspace names. Output names need a running session (DISP-003).

## Fix

Shows the corrected rule. Report-only: the doctor changes nothing.
