# BAR-001: i3xrocks conf.d files the parser mishandles

| | |
|---|---|
| Area | BAR |
| Sessions | i3 (X11) |
| Releases | Regolith 3.4, 3.5 |
| Needs | files only |
| Fix class | auto |
| Status | planned |

## What it detects

Files in the i3xrocks `conf.d` folder that the bar reads wrongly: a file whose last line has no newline loses that line, editor backups and swap files load as extra blocks, one broken file stops the rest from loading, and a user `conf.d` can hide the shipped blocks.

## How it is detected

The doctor scans `~/.config/regolith3/i3xrocks/conf.d` and the shipped `/usr/share/i3xrocks/conf.d` for files whose last byte is not a newline, names that match editor or package-manager leftovers, and blocks that fail to parse.

## Fix

The doctor adds the missing newline and moves leftover files aside. Auto: the change stays inside HOME, is backed up and can be undone.
