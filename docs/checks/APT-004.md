# APT-004: Release channel or series does not match what is installed

| | |
|---|---|
| Area | APT |
| Sessions | i3 (X11) and sway (Wayland) |
| Releases | Regolith 3.4, 3.5 |
| Needs | files only |
| Fix class | report-only (guided when removing a duplicate entry) |
| Status | planned |

## What it detects

The configured Regolith series (`vX.Y` component) differs from the series that is installed, `testing` or `unstable` is used by accident, or two Regolith entries for different series or channels are active at the same time. Upgrades then pull packages from an unexpected release.

## How it is detected

From the parsed sources the doctor lists channel, codename and component for each Regolith entry. It reads `REGOLITH_VERSION` from `/etc/regolith/version` and the `regolith-desktop` version from `/var/lib/dpkg/status`, and reports more than one Regolith entry or a channel or series that differs from the installed one.

## Fix

The doctor explains the difference and can comment out an extra entry. Report-only for the mismatch itself; removing a duplicate entry is guided and needs your confirmation.
