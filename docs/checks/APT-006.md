# APT-006: Regolith source disabled by a distribution upgrade

| | |
|---|---|
| Area | APT |
| Sessions | i3 (X11) and sway (Wayland) |
| Releases | Regolith 3.4, 3.5 |
| Needs | files only |
| Fix class | guided |
| Status | planned |

## What it detects

A release upgrade turned the Regolith entry off: it commented the line out with a `disabled on upgrade to <codename>` note, renamed the file to `*.distUpgrade` or `*.save`, or set `Enabled: no`. Regolith packages then stay on the old release or get removed.

## How it is detected

The doctor looks for commented Regolith lines carrying the upgrade marker, deb822 stanzas with `Enabled: no`, and `.distUpgrade` or `.save` files next to the source files. Installed packages whose version still carries the old codename (see PKG-001) confirm the case.

## Fix

The doctor re-enables the entry with the current codename, using the same rewrite as APT-001, after a backup. Guided: you confirm before anything changes.
