# SES-008: Regolith runtime state is a symlink into a version-controlled checkout

| | |
|---|---|
| Area | SES |
| Sessions | i3 (X11) and sway (Wayland) |
| Releases | Regolith 3.4, 3.5 |
| Needs | files only |
| Fix class | report-only |
| Status | planned |

## What it detects

`~/.config/regolith3`, or its `flags/` or `kanshi/profiles` folders, is a symlink into a version-controlled tree. On a new machine the first-login setup is skipped because the flags already exist, and Regolith tools write their state into the repository.

## How it is detected

The doctor checks those paths with `lstat` and looks for a `.git` directory above the link target.

## Fix

The doctor reports it and suggests linking files rather than whole folders (`stow --no-folding`) and ignoring `flags/`. Report-only.
