# CFG-010: Keybinding help cannot show a binding

| | |
|---|---|
| Area | CFG |
| Sessions | i3 (X11) and sway (Wayland) |
| Releases | Regolith 3.4, 3.5 |
| Needs | files only |
| Fix class | report-only |
| Status | planned |

## What it detects

User bindings that the keybinding page of ilia (or remontoire) cannot list: `bindsym` lines without a `## Group // Action // Keys ##` comment above them, or malformed `##` comments that can empty the whole page.

## How it is detected

Checks the comment grammar for every binding in the user partials and flags `##` lines that do not parse.

## Fix

Suggests a correct comment line for each binding. Report-only: the doctor changes nothing.
