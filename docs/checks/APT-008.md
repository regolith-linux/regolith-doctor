# APT-008: Base release not supported by the installed or configured Regolith series

| | |
|---|---|
| Area | APT |
| Sessions | i3 (X11) and sway (Wayland) |
| Releases | Regolith 3.4, 3.5 |
| Needs | files only |
| Fix class | report-only |
| Status | planned |

## What it detects

The Ubuntu or Debian release the system runs has no build in the chosen Regolith series, for example Ubuntu 25.04 after its support ended, Debian 13 before its packages existed, or Ubuntu 26.04 with a series older than 3.5. apt cannot install or upgrade Regolith.

## How it is detected

The doctor compares the codename from `/etc/os-release` and the configured component with a support table shipped with the doctor (series, codename and architecture). No network access is needed.

## Fix

The doctor explains which Regolith series supports this release. Report-only: nothing is changed.
