# PKG-009: Third-party package known to break Regolith

| | |
|---|---|
| Area | PKG |
| Sessions | i3 (X11) and sway (Wayland) |
| Releases | Regolith 3.4, 3.5 |
| Needs | files only |
| Fix class | report-only |
| Status | planned |

## What it detects

A package from outside Regolith is known to interfere: another notification daemon (dunst, xfce4-notifyd, notify-osd), `netcat-traditional` instead of `netcat-openbsd` (breaks the rofication counter), `xserver-xorg-input-synaptics` overriding libinput, a PPA Mesa that differs from the system Mesa, or stock i3 config packages.

## How it is detected

The doctor checks `/var/lib/dpkg/status` against a list shipped with the doctor. For Mesa it compares the origin and version suffix of `libgl1-mesa-dri` with the distribution's.

## Fix

The doctor explains the conflict and the removal or setting that avoids it. Report-only: nothing is changed.
