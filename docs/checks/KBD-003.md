# KBD-003: Keyboard layout set in several places that disagree

| | |
|---|---|
| Area | KBD |
| Sessions | i3 (X11) and sway (Wayland) |
| Releases | Regolith 3.4, 3.5 |
| Needs | files only |
| Fix class | guided |
| Status | planned |

## What it detects

The layout is configured in more than one place: GNOME input sources, `input type:keyboard xkb_layout` in a user partial, `XKB_DEFAULT_*` variables in environment files, or `setxkbmap` in `~/.xprofile`. They fight, and regolith-inputd applies the GNOME list again at every start and reload, so the layout seems to change by itself.

## How it is detected

The doctor collects the layout from each of these places and reports when they do not agree. It also notes `input *` blocks that end up applying to keyboards.

## Fix

The doctor offers to store the layout in the GNOME input sources and remove the other settings. Guided: the change is shown and applied only after you confirm.
