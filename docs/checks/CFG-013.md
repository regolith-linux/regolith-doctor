# CFG-013: Dead lines in user partials

| | |
|---|---|
| Area | CFG |
| Sessions | i3 (X11) and sway (Wayland) |
| Releases | Regolith 3.4, 3.5 |
| Needs | files only |
| Fix class | report-only |
| Status | planned |

## What it detects

Lines that have no effect: partials that contain only `set` lines, an `exec` of a resource that expands to nothing (`exec :`), `set_from_resource` variables that nothing uses, and resource keys no component reads.

## How it is detected

Tracks where each variable is defined and used across the effective include list, and checks resource keys against the key catalogue built for XRES-001.

## Fix

Reports the dead lines. Report-only: the doctor changes nothing.

## Sources

- Found while reviewing a real user configuration.
