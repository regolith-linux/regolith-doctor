# BAR-004: The system tray is not shown

| | |
|---|---|
| Area | BAR |
| Sessions | i3 (X11) mostly |
| Releases | Regolith 3.4, 3.5 |
| Needs | a running session (recorded output can be replayed) |
| Fix class | guided |
| Status | planned |

## What it detects

Tray icons do not appear. On X11 this happens when the bar uses `tray_output primary` but no output is marked primary; it also happens when another program owns the tray (another StatusNotifierWatcher or indicator host).

## How it is detected

The doctor combines the bar configuration with the live primary output and the current D-Bus owner of `org.kde.StatusNotifierWatcher`.

## Fix

The doctor suggests setting the `wm.bar.trayoutput` resource. Guided: the change is shown and applied only after you confirm.
