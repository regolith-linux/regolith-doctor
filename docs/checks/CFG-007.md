# CFG-007: Regolith 2 names in user partials, or variables that are never defined

| | |
|---|---|
| Area | CFG |
| Sessions | i3 (X11) and sway (Wayland) |
| Releases | Regolith 3.4, 3.5 |
| Needs | files only |
| Fix class | guided (the pure `i3-wm.` to `wm.` rename could be auto) |
| Status | planned |

## What it detects

User partials that still use `$i3-wm.*` variables or `i3-wm.*` resource keys (renamed to `wm.*` in 3.0), variables that were removed or moved between partials, or any `$name` that is still there after expansion. i3 and sway keep an undefined variable as literal text, so the bar can end up with a colour like `$i3-wm.bar.background.color`.

## How it is detected

After variable expansion over the effective include list, any `$` token left on a directive line is reported; explicit `i3-wm.` names are matched against the rename table shipped with the doctor.

## Fix

Shows the `i3-wm.` to `wm.` rename as a diff and applies it on request. Guided: applied only after confirmation.
