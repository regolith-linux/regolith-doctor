# BAR-002: A bar block needs a command or package that is missing

| | |
|---|---|
| Area | BAR |
| Sessions | i3 (X11) for i3xrocks blocks; sway (Wayland) for i3status-rust blocks |
| Releases | Regolith 3.4, 3.5 |
| Needs | files only |
| Fix class | report-only |
| Status | planned |

## What it detects

A status bar block calls a program that is not installed, so the block stays empty or shows an error. Common examples are `pactl`, `amixer -D pulse` on a PipeWire system, `bc`, `acpi`, `nmcli`, and scripts from blocklet packages that were removed.

## How it is detected

The doctor parses the `command=` lines of the blocks, looks each program up in the PATH directories under the root (the same resolver as CFG-008), and maps it to the package that ships it.

## Fix

The doctor names the package to install. Report-only: nothing is changed.
