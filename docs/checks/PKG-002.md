# PKG-002: Core Regolith packages at risk of autoremove

| | |
|---|---|
| Area | PKG |
| Sessions | i3 (X11) and sway (Wayland) |
| Releases | Regolith 3.4, 3.5 |
| Needs | files only |
| Fix class | auto (root only, reversible) |
| Status | planned |

## What it detects

`regolith-desktop` is not installed while a session package is, or core packages are marked as automatically installed. The next `apt autoremove` or distribution upgrade can then remove the whole desktop.

## How it is detected

The doctor reads `/var/lib/dpkg/status` and `/var/lib/apt/extended_states` (`Auto-Installed: 1`) for packages such as `regolith-desktop`, `regolith-session-flashback`, `regolith-session-sway` and `regolith-wm-config`, and works out reverse dependencies from the status file.

## Fix

The doctor marks the packages as manually installed (`apt-mark manual`), which `apt-mark auto` undoes. Auto: it may apply this itself, with a backup and undo, but only as root with `--yes`.
