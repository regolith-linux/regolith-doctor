# CFG-004: WM config in a place Regolith does not read, or a root config that hides the shipped partials

| | |
|---|---|
| Area | CFG |
| Sessions | i3 (X11) and sway (Wayland) |
| Releases | Regolith 3.4, 3.5 |
| Needs | files only |
| Fix class | guided |
| Status | planned |

## What it detects

Config files Regolith ignores because it starts the window manager with its own config: `~/.config/i3/config`, `~/.i3/config`, `~/.config/sway/config`. Also a full user root config in `~/.config/regolith3/{i3,sway}/config`, which replaces Regolith's root config and so misses every partial added later; partials put in the i3 folder while running sway; and nested `config.d` folders.

## How it is detected

Path checks in HOME. For a user root config, its `include` lines are compared with `/etc/regolith/<wm>/config`, and the shipped partials it no longer loads are listed.

## Fix

Explains where the file belongs and offers to move it into `config.d` as a partial. Guided: moved only after confirmation.
