# BAR-003: A bar block points at hardware that is not there

| | |
|---|---|
| Area | BAR |
| Sessions | i3 (X11) and sway (Wayland) |
| Releases | Regolith 3.4, 3.5 |
| Needs | files only |
| Fix class | guided |
| Status | planned |

## What it detects

A block is configured for a device the machine does not have: a battery missing from `/sys/class/power_supply`, a temperature sensor missing from `/sys/class/hwmon`, or a network interface that belongs to a VPN or a virtual machine. The block shows nothing useful.

## How it is detected

The doctor compares the instance settings of each block with the devices listed under `/sys` inside the root.

## Fix

The doctor suggests the instance that matches the hardware present. Guided: the change is shown and applied only after you confirm.
