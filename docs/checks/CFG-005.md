# CFG-005: More than one bar

| | |
|---|---|
| Area | CFG |
| Sessions | i3 (X11) and sway (Wayland) |
| Releases | Regolith 3.4, 3.5 |
| Needs | files only |
| Fix class | guided |
| Status | planned |

## What it detects

The effective config contains more than one `bar {}` block, so two bars are stacked on screen. The usual cause is a user bar partial next to a shipped bar partial that is still installed; in sway the shipped file is `70_bar_i3status-rs`, so the names do not even match. A user bar that replaces a removed bar package is fine, and no bar at all is PKG-004.

## How it is detected

Counts `bar {` blocks across the effective include list, built only from partials that are present (installed package, file on disk), and attributes each to its file. With a running session, `i3-msg -t get_bar_config` or `swaymsg -t get_bar_config` returning more than one id confirms it.

## Fix

Offers the Xresources keys that change the shipped bar (`wm.bar.status_command`, `wm.bar.font`, `wm.bar.position`) and to disable the user bar partial. Guided: applied only after confirmation.
