# PKG-008: Installed version has a known, fixed bug

| | |
|---|---|
| Area | PKG |
| Sessions | i3 (X11) and sway (Wayland) |
| Releases | Regolith 3.4 mostly, some 3.5 betas |
| Needs | files only |
| Fix class | report-only (guided for the regolith-session 1.2.0 drop-in) |
| Status | planned |

## What it detects

An installed package has a version with a user-visible bug that a later version fixed. Examples: regolith-session 1.2.0 (X11 target shadowing, no XSettings or portal), ilia before 0.19 (freezes while typing) and before 0.20 (blocks keys while open, keybindings page ignores Xresources), i3xrocks-config 5.5.3 (PipeWire volume, temperature), i3 before 4.22 with 3.2 gaps directives, the picom v10 crash, powerd before its AC detection fix, wm-config before the Super/Alt swap and `--locked` brightness fixes, and inputd 0.6.0 with IBus hotplug.

## How it is detected

A table shipped with the doctor lists package, affected version range, symptom, fixed version and a link. Installed versions from `/var/lib/dpkg/status` are matched against it with Debian version comparison.

## Fix

The doctor names the fixed version and how to get it (an upgrade, or which series has it). For regolith-session 1.2.0 it offers the documented systemd drop-in. Report-only, except the drop-in, which is guided.
