# SES-004: No polkit agent in the session

| | |
|---|---|
| Area | SES |
| Sessions | i3 (X11) and sway (Wayland) |
| Releases | Regolith 3.4, 3.5 |
| Needs | files only |
| Fix class | guided |
| Status | planned |

## What it detects

No polkit agent runs, so App Center, Update Manager and settings dialogs fail with `login-required` or never ask for a password.

## How it is detected

The doctor checks the regolith-session version against the releases that fixed agent startup, and looks for installed polkit agent packages. In a running session it checks for the agent process or its D-Bus registration.

## Fix

The doctor names the package to install or the upgrade that fixes it. Guided: you confirm first.
