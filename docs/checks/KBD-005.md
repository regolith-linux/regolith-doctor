# KBD-005: Input method forced in a way that breaks typing

| | |
|---|---|
| Area | KBD |
| Sessions | i3 (X11) and sway (Wayland) |
| Releases | Regolith 3.4, 3.5 |
| Needs | files only |
| Fix class | report-only |
| Status | planned |

## What it detects

Input-method variables such as `GTK_IM_MODULE=xim`, `QT_IM_MODULE` or `XMODIFIERS` are exported for every session, or IBus is turned on with im-config under sway. Dead keys stop working or text input misbehaves; an IBus hotplug bug in regolith-inputd can add to this.

## How it is detected

The doctor reads environment files (`~/.profile`, `~/.config/environment.d/*.conf`, `~/.pam_environment`), `~/.xinputrc`, the im-config state and the `regolith.experimental.ibus` resource.

## Fix

The doctor explains which setting causes the problem and where it is set. Report-only: nothing is changed.
