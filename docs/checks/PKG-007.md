# PKG-007: Regolith files changed or missing on disk (dpkg verify)

| | |
|---|---|
| Area | PKG |
| Sessions | i3 (X11) and sway (Wayland) |
| Releases | Regolith 3.4, 3.5 |
| Needs | files only |
| Fix class | guided |
| Status | planned |

## What it detects

Conffiles under `/etc/regolith` were deleted, which a plain `apt reinstall` does not restore, or files in `/etc/regolith` or `/usr/share/regolith` were edited in place, so the change is lost or goes stale on the next upgrade.

## How it is detected

For conffiles the doctor compares the md5 in the `Conffiles:` field of `/var/lib/dpkg/status` with the file on disk; for other files it uses `/var/lib/dpkg/info/<pkg>.md5sums`. Only Regolith packages are checked.

## Fix

For a missing conffile the doctor shows `apt install --reinstall -o Dpkg::Options::=--force-confmiss <pkg>`. For an edited shipped file it shows the difference and the user-level place where the change belongs. Guided: you confirm each step.
