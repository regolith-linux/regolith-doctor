# SES-002: User environment overrides the session's identity or toolkit backends

| | |
|---|---|
| Area | SES |
| Sessions | i3 (X11) and sway (Wayland) |
| Releases | Regolith 3.4, 3.5 |
| Needs | files only |
| Fix class | guided |
| Status | planned |

## What it detects

Variables such as `XDG_CURRENT_DESKTOP`, `XDG_SESSION_DESKTOP`, `XDG_SESSION_TYPE`, `QT_QPA_PLATFORM`, `SDL_VIDEODRIVER`, `GDK_BACKEND`, `CLUTTER_BACKEND` or `ELECTRON_OZONE_PLATFORM_HINT` are set for every session. Qt apps then fail under X11, and portals and GNOME overrides that need `Regolith` in `XDG_CURRENT_DESKTOP` stop working.

## How it is detected

The doctor reads `~/.config/environment.d/*.conf`, `~/.profile`, `~/.pam_environment` and `/etc/environment`. In a running session it also reads `systemctl --user show-environment`.

## Fix

The doctor offers to move the lines into the per-session files `~/.config/regolith3/sway/env` or `~/.config/regolith3/i3/env`. Guided: moved only after you confirm.
