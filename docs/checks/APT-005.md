# APT-005: Regolith source does not match the platform (Ubuntu vs Debian, architecture)

## What it detects

The Regolith entry is for the wrong family or architecture: an `/ubuntu/` path on Debian, a `/debian/` path on Ubuntu, `[arch=amd64]` on an arm64 machine, or an architecture the archive does not build. apt finds no usable packages.

## How it is detected

The doctor reads `ID` and `ID_LIKE` from `/etc/os-release` and the native architecture from `/var/lib/dpkg/arch` or the `Architecture:` of the `dpkg` package in `/var/lib/dpkg/status`. It compares them with the entry's URI path and its `arch=` or `Architectures:` option, and with the architectures listed in a table shipped with the doctor.

## Fix

The doctor rewrites the entry for the right family and architecture. Guided: applied only after you confirm.
