# APT-007: Derivative distribution: wrong codename in the source or unsupported base

| | |
|---|---|
| Area | APT |
| Sessions | i3 (X11) and sway (Wayland) |
| Releases | Regolith 3.4, 3.5 |
| Needs | files only |
| Fix class | guided |
| Status | planned |

## What it detects

On Linux Mint, Pop!_OS, Zorin, elementary and other derivatives the Regolith entry uses the derivative's own codename instead of its Ubuntu or Debian base. Derivatives also have known side effects, such as Mint's codename making the session start gnome-session with `--builtin`, Mint's `grp:win_space_toggle` option, or a missing polkit agent.

## How it is detected

When `ID` in `/etc/os-release` is neither `ubuntu` nor `debian`, the doctor reads `UBUNTU_CODENAME` or `DEBIAN_CODENAME` and expects the Regolith suite to equal that base codename. Known caveats per derivative come from a table shipped with the doctor.

## Fix

The doctor rewrites the suite to the base codename and lists the caveats for the derivative. Guided: applied after you confirm.
