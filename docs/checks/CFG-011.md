# CFG-011: The window manager itself rejects or warns about the config

| | |
|---|---|
| Area | CFG |
| Sessions | i3 (X11) and sway (Wayland) |
| Releases | Regolith 3.4, 3.5 |
| Needs | programs installed on the system, no running session |
| Fix class | report-only |
| Status | planned |

## What it detects

Errors and warnings that only the window manager reports: i3's `Duplicate keybinding` and unknown directives, sway's `Overwriting binding` and `Error on line`. Note that `sway -C` alone is silent about overwritten bindings; they only show with `-d`.

## How it is detected

Runs `i3 -C -c <root config>` and `sway -C -d -c <root config>` as the user with the user's HOME (sway headless, with `WLR_BACKENDS=headless WLR_RENDERER=pixman LIBSEAT_BACKEND=noop`), reads the exit code and messages, and maps each message to the file and line it came from.

## Fix

Reports each message with its file and line, and points to the CFG-001 or CFG-007 fix where one applies. Report-only: the doctor changes nothing.
