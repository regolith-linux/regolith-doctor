# SES-006: The display manager starts another session by default

| | |
|---|---|
| Area | SES |
| Sessions | i3 (X11) and sway (Wayland) |
| Releases | Regolith 3.4, 3.5 |
| Needs | files only |
| Fix class | report-only |
| Status | planned |

## What it detects

The user keeps ending up in GNOME (`DESKTOP_SESSION=ubuntu`) instead of Regolith after logging in.

## How it is detected

The doctor reads `Session=` and `XSession=` from `/var/lib/AccountsService/users/<user>` and compares them with the installed session files.

## Fix

The doctor explains how to pick the Regolith session at the login screen. Report-only.
