# CFG-006: The same daemon is started twice

| | |
|---|---|
| Area | CFG |
| Sessions | i3 (X11) and sway (Wayland) |
| Releases | Regolith 3.4, 3.5 |
| Needs | files only |
| Fix class | guided |
| Status | planned |

## What it detects

A user partial repeats an `exec` that an installed shipped partial already runs, for example rofication-daemon, kanshi, picom, a polkit agent or `regolith-sway-publish-display-env`. The two copies fight over a D-Bus name or a socket.

## How it is detected

Takes the first word of every `exec` and `exec_always` across the include list, after stripping wrappers such as `--no-startup-id` and `systemd-run --user --scope`, and reports programs started by both a user file and a shipped file. Only shipped partials whose package is installed and whose file is on disk count. NOTIF-002 confirms the duplicate in a running session.

## Fix

Offers to remove the duplicate line from the user partial. Guided: removed only after confirmation.
