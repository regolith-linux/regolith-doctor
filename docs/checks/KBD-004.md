# KBD-004: Swapped modifiers break user bindings

| | |
|---|---|
| Area | KBD |
| Sessions | i3 (X11) and sway (Wayland) |
| Releases | Regolith 3.4, 3.5 |
| Needs | files only |
| Fix class | report-only |
| Status | planned |

## What it detects

The user swapped `wm.mod` and `wm.alt`, but their own partials hard-code `Mod1` or `Mod4`, so those bindings end up on the wrong key. On older wm-config releases, `wm.mod: Mod1` could also create duplicate bindings.

## How it is detected

The doctor compares the modifier resources with the literal modifiers used in user partials, and uses the installed wm-config version (see PKG-008) to tell whether the duplicate-binding bug applies.

## Fix

The doctor suggests writing `$mod` and `$alt` in user bindings instead of fixed modifier names. Report-only: nothing is changed.
