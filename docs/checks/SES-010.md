# SES-010: systemd-oomd kills the whole session

| | |
|---|---|
| Area | SES |
| Sessions | i3 (X11) and sway (Wayland) |
| Releases | Regolith 3.4, 3.5 |
| Needs | files only |
| Fix class | report-only |
| Status | planned |

## What it detects

Under memory pressure systemd-oomd kills the whole session scope, and the user lands back at the login screen.

## How it is detected

The doctor checks whether `systemd-oomd` is enabled and which `ManagedOOM` settings apply to the user slice. In a running session it also looks for the matching journal lines.

## Fix

The doctor reports the configuration that allows it. Report-only.
