# SES-007: gnome-flashback fixes overridden by user dconf

| | |
|---|---|
| Area | SES |
| Sessions | i3 (X11) |
| Releases | Regolith 3.4, 3.5 |
| Needs | files only |
| Fix class | guided |
| Status | planned |

## What it detects

Regolith's GSettings overrides for the X11 session (tray icons, notifications, no desktop window) lose to values the user set, for example `org.gnome.gnome-flashback desktop true`, which shows a 'Desktop' window.

## How it is detected

The doctor reads Regolith's `*.gschema.override` files in `/usr/share/glib-2.0/schemas` and compares them with the user's dconf values for the same keys. The overrides only apply when `XDG_CURRENT_DESKTOP` contains `Regolith`.

## Fix

The doctor resets the user value and keeps the old one for undo. Guided: applied after you confirm.
