# CFG-014: Editor and package-manager leftovers load as partials

| | |
|---|---|
| Area | CFG |
| Sessions | i3 (X11) and sway (Wayland) |
| Releases | Regolith 3.4, 3.5 (ignored once regolith-wm-config PR 133 ships) |
| Needs | files only |
| Fix class | auto (reversible move inside HOME) |
| Status | planned |

## What it detects

Files such as `30_navigation~`, `.swp`, `.dpkg-old`, `.orig` or `.bak` inside `config.d` folders (and in the i3xrocks `conf.d`). Released 3.4 and 3.5 load them like any other partial, so everything in them is applied twice.

## How it is detected

Lists files that match leftover name patterns in the four `config.d` folders. Whether they are actually loaded depends on the loading mode CFG-002 works out.

## Fix

Moves the leftovers into a backup folder. Auto: the doctor may do this itself because the move stays inside HOME and can be undone.
